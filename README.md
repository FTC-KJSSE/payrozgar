# PayRozgar - Modern Payroll Management System

A modern payroll management system designed for small businesses. 
Built with vanilla HTML, CSS, and JavaScript following Emil Kowalski's design engineering principles.


## 🏗 **Architecture**

```
PayRozgar/
├── index.html          # Main HTML structure
├── styles.css          # Sophisticated CSS with animations
├── app.js             # Vanilla JS with Emil's principles
├── manifest.json      # PWA configuration
├── sw.js              # Service Worker for offline support
└── README.md          # This beautiful documentation
```

## 🎪 **Live Demo Features**

- **Auto-login**: Automatically fills credentials and logs in
- **Sample Data**: Pre-populated employees and payroll data
- **Interactive Attendance**: Click status buttons (P/A/HD/L)
- **Smooth Navigation**: Swipe between screens
- **Toast Notifications**: Swipe up to dismiss
- **Loading States**: Realistic API simulation delays
